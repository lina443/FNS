# Налоговая задолженность в РФ: 2020–2024

Аналитическая записка по открытым данным о налоговой задолженности в Российской Федерации.

🔗 **[Открыть отчёт](https://lina443.github.io/tax-debt-report/)**

-----

## О проекте

Задача — самостоятельно собрать открытые данные, выявить закономерности и сформулировать обоснованные предложения.

**Период исследования:** 2020–2024  
**Формат:** один самодостаточный HTML-файл, работает без интернета и внешних зависимостей

## Структура отчёта

**1. Данные**  
Три разреза с атрибуцией каждой цифры:

- общая задолженность по годам + самостоятельно рассчитанный debt-to-income (задолженность / поступления)
- поступления и динамика задолженности по видам налогов (НДС, прибыль, НДФЛ, страховые взносы, имущественные)
- разбивка ЮЛ / ФЛ с отдельным блоком по банкротству

Методологическая оговорка вынесена явно: с 2023 г. в дебиторскую задолженность включены страховые взносы (+644 млрд) — технический сдвиг ЕНС, не реальный рост долга.

**2. Визуализация**  
Три диаграммы на SVG, без внешних библиотек:

- debt-to-income 2020–2024, расчёт автора (со средней линией и аннотациями аномалий)
- динамика поступлений по трём видам налогов за 5 лет (сгруппированная столбчатая)
- декомпозиция прироста дебиторской задолженности 2023: методологический сдвиг vs реальный прирост

**3. Анализ**  
Пять интерпретационных блоков — не пересказ цифр:

- долгосрочное снижение относительного долга и его причины
- COVID-аномалия 2021 как сознательная антикризисная мера
- декомпозиция пика 2023: 54,5% прироста — методологический сдвиг ЕНС
- концентрация долга при снижении числа должников — слепая зона МСП
- структурные уязвимости: банкротство (разрыв 21% vs 55,3%) и схемы НДС

**4. Предложения**  
Пять мер с измеримыми KPI, упорядоченных по потенциальному объёму взыскания:

1. Обязательный реструктуризационный трек перед банкротством для МСП (цель: +330 млрд)
1. Расширение АСК НДС-2 на многоуровневые схемы ротации контрагентов
1. Светофор задолженности в ЛК ЮЛ с автоматикой перехода к взысканию
1. Проактивные уведомления физлицам за 90/30/10 дней через Госуслуги
1. Квартальный публичный мониторинг по 8 видам налогов в формате CSV + дашборд

**5. Источники**  
9 первичных источников с указанием конкретных данных из каждого.
